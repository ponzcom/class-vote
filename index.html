💡 第一次使用自己的 Firebase？點我看 2 個必開設定

1. 前往 Firebase 控制台 → Authentication（驗證） → Sign-in method → 開啟 「匿名 (Anonymous)」登入。

2. 前往 Firestore Database → 規則 (Rules)，貼上以下規則並發布：

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{appId}/public/data/{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
